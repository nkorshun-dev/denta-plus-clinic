# Дента Плюс — сайт стоматологической клиники

Демо-проект для портфолио. Клиника и все данные вымышленные, формы никуда ничего не отправляют.

**Демо:** https://nkorshun-dental.netlify.app
**Связанный проект:** проект 6 — CRM-панель этой клиники. Она берёт врачей, услуги, цены и графики из того же файла `js/data.js`.

## Скриншоты

Положите картинки в `docs/` и подставьте ссылки:

- `docs/home.png` — главная
- `docs/booking.png` — запись, шаг «Дата и время»
- `docs/price.png` — прайс с поиском
- `docs/calculator.png` — калькулятор лечения

## Что умеет

- Многошаговая запись к врачу: услуга → врач → дата и время → контакты → подтверждение. Шаги зависят друг от друга: врачу не показываются чужие услуги, смена услуги или врача сбрасывает выбранное время.
- Прайс (33 услуги, 6 категорий) с поиском: без учёта регистра и буквы «ё», с подсветкой и debounce. Категория открывается из `?category=…`.
- Калькулятор лечения с количеством для штучных услуг, анимацией суммы и рассрочкой 3 / 6 / 12 месяцев (12 мес. — +7%).
- Страницы 9 врачей, генерируются из данных (`doctor.html?id=d1`), с ближайшими свободными окнами.
- Файл `.ics` для календаря, генерируется в браузере.
- Черновик записи хранится в `localStorage` и восстанавливается, после успешной записи очищается.
- Доступность: подписи полей, `aria-live`, видимый фокус, работа с клавиатуры, `prefers-reduced-motion`.
- SEO: уникальные title и description, Open Graph, canonical, JSON-LD (Dentist, Physician).

## Стек

HTML5, CSS3, ванильный JavaScript (ES-модули). Без сборки, без зависимостей.

## Как устроена генерация слотов

Всё в `js/slots.js`, функции чистые: время «сейчас» передаётся аргументом.

1. График врача в `data.js`: `schedule[день недели] = [[начало, конец], ...]`. Нет дня — выходной; несколько диапазонов — смена с перерывом.
2. Начало приёма каждые 30 минут внутри диапазона. Слот создаётся, только если услуга целиком помещается до конца диапазона (`начало + длительность <= конец`), поэтому длинная услуга не занимает последнее окно дня.
3. «Занято» вычисляется детерминированно: `hash(врач | дата | минуты) % 100 < 32` (FNV-1a). Одинаковые входные данные дают одинаковый результат, поэтому после перезагрузки занятые окна те же. Услуга длиннее 30 минут занята, если занята любая из её 30-минутных ячеек.
4. Сегодня недоступно время, которое уже прошло. Календарь показывает 21 день вперёд; переход через конец месяца и года делает `new Date(y, m, d + n)`.
5. «Любой врач»: `mergedDaySlots` объединяет окна всех подходящих врачей, при выборе времени берётся первый врач со свободным окном.

## Где менять врачей и цены

Только в `js/data.js`. Услуги врача выводятся автоматически из поля `doctors` у услуги. Цена «от» помечается `from: true`, штучная услуга для калькулятора — `qty: true`.

## Запуск локально

Нужен Node.js. ES-модули не работают при открытии файла двойным кликом, нужен сервер:

```
npx serve -l 5192 .
```

Откройте http://localhost:5192

## Деплой на Netlify

Перетащите папку проекта на https://app.netlify.com/drop или подключите репозиторий: настройки уже в `netlify.toml` (publish = ".", сборки нет).
